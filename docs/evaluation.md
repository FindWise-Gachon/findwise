# 위치 예측 평가 초안

1. `IncidYear`와 `CaseNumber`로 IPP와 발견점을 연결합니다. 일대다·다대다 사례는 원자료 근거로 해소하거나 제외 사유를 집계합니다. 키, 좌표, 위치 의미, 지리참조 오차를 확인한 뒤 코호트와 입력 기준을 버전화합니다.
2. 학습·검증·최종 평가를 사건 단위로 분리합니다. 동일 사건의 여러 위치 후보나 모의 실행도 같은 분할에 둡니다. 데이터 검토 후 분할 목록과 수색 면적 예산을 고정합니다.
3. 각 사건의 격자는 IPP와 사전에 고정한 거리·방향 규칙으로 정합니다. 화면 개발용 요세미티 사각형은 별도로 관리합니다. 발견점 및 발견까지 걸린 시간은 격자, 모델 입력, 전처리, 최종 평가 파라미터 선택에서 제외합니다.
4. 첫 기준 모델은 IPP부터 셀 중심까지의 거리로 순위를 매깁니다. 같은 면적 예산에서 포함된 발견점 비율을 비교합니다. 동점은 격자 행 우선 인덱스로 처리합니다. 영역 밖 또는 결측 셀의 발견점은 미포함으로 세고 별도로 집계합니다. 좌표가 없거나 연결을 확정할 수 없는 사건은 제외 사유와 함께 분모 밖에 집계합니다.
5. 보고 처리 실험은 합성 시나리오로 별도 평가합니다. 사람의 검토·승인 후 지도에 반영합니다.

## 데이터 연결 규칙

- **격자**는 프론트에서 내보낸 버전 1 JSON을 그대로 사용합니다. 격자 ID, CRS, 북서 원점, 셀 크기, 행·열, 지오트랜스폼을 공유합니다. 배열은 북→남 행, 서→동 열 순서입니다. 서·북 경계를 포함하고 동·남 경계를 제외합니다.
- **지형 결과**는 같은 모양의 `elevation_m`, `slope_deg`, `valid` 배열과 JSON 문자열 `metadata`를 포함하는 NPZ입니다. 고도나 경사를 계산할 수 없는 값은 NaN입니다. `valid`는 두 값이 모두 있는 셀을 표시합니다. 메타데이터에 격자, 출처 버전, 단위·수직 기준과 처리 방법을 기록합니다.
- **거리 기준 미리보기**는 현재 개발 격자의 모든 셀을 대상으로 투영 거리 순위를 계산합니다. 내보낸 실행 조건 JSON에는 모델 버전, 격자, 시작 좌표, 순위와 동점 규칙을 기록합니다. 사건별 평가에서는 위에서 정의한 별도의 영역 및 유효 셀 규칙을 적용합니다.
- **향후 모델 결과**는 실행 ID, 격자 ID, 입력 자료와 모델 버전, 값의 의미, 결측·영역 밖 처리 규칙을 함께 내보냅니다. 지도는 같은 격자의 결과만 표시합니다. 위치 분포와 수색 우선순위는 각각 정의합니다.
